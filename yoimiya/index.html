ものがたり

十二年ぶりに、母の田舎の夏祭りへ帰ってきた。
この春に亡くなった祖父は、山の神社の宮司だった。
参道の提灯は、村の家の数だけ吊るす決まり。
――なのに、祭りの夜がくるたび、提灯がひとつ多い。

参道の入口には、昼にはなかった高札。
「提灯を数えよ。いつもと違えば、鈴を鳴らさず鳥居へ戻れ。三たび続けて誤れば、鬼となる。」

昼は村を歩いて、祖父が隠していたことを調べる。
夜は掟の参道で、62の異変を見抜く。
四日間の祭りの最後に、古井戸で何を言うか。

ゲーム画面

※画面は英語版です。ゲームは日本語／English を選べます。

特徴

  • 一人称で歩く和風ホラー。昼の調べものと、夜の「異変を見抜く」参道。
  • 異変62種（提灯・人・屋台・参道の物・空・音）。すぐ分かるものから気づきにくいものまで、夜が進むほど難しくなります。1回の通しプレイで同じ異変は出ません。
  • 四日間：神社、祖父の家と蔵、分校の跡・墓地・ナツの家・川のある村。夜ごとに灯す提灯が増えます（3・5・6・7）。
  • ミニゲーム6種：金魚すくい・型抜き・射的・太鼓・提灯の火入れ・灯籠流し。
  • エンディング6種（BAD 4・GOOD・VERY GOOD）。エンディング一覧とヒントつき。
  • むずかしさは「ふつう」と「やさしい」。夜の参道のヒント（異変の種類だけ／種類と場所）も選べます。どれも遊んでいる途中で変えられます。
  • 記録3枠＋自動記録、分岐点からやり直し。日本語／English。
  • 画質は4段階から選べます（とても軽い／軽い／標準／高い）。
  • 実況・動画投稿は自由です（クレジット不要）。

動く環境・操作

  • パソコン（Windows）のブラウザで遊びます。ダウンロードしたzipの中の index.html を開くだけで、ネットにつながっていなくても遊べます。
  • Google Chrome と Microsoft Edge で動作を確かめています。
  • スマホ・タブレットでも動く作りですが、ダウンロードしたファイルを開ける環境が必要なため、パソコンをおすすめします。
  • 操作：WASD／矢印キーで歩く、マウスで見る、E で話す・調べる・鈴、H でヒント、Esc でメニュー。

ご注意

  • ホラー表現（暗い場面・突然の音・赤い光）があります。設定で点滅と赤い光を弱められます。
  • 記録は、遊んでいるパソコンのブラウザの中だけに残ります。ブラウザのデータを消すと記録も消えます。
  • 登場する人物・団体・地名は、すべて架空のものです。
